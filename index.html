InteractorGate

Escribir mensajes con la mirada, usando una cámara web común

Aplicación de comunicación aumentativa y alternativa para personas adultas con discapacidad motriz. Se controla con los ojos y sugiere frases para escribir con menos esfuerzo.

Prototipo de investigación InteractorGate forma parte de un proyecto de tesis y se está evaluando con participantes. La instalación la realiza el equipo de investigación junto con cada participante, después de firmar el consentimiento informado. Si llegaste aquí por otro motivo, escríbenos antes de instalarla.

Qué necesitas

  • ✓Una computadora con Windows 10 u 11 de 64 bits. No hace falta tarjeta gráfica dedicada.
  • ✓Una cámara web común, integrada o por USB, frente al rostro.
  • ✓Conexión a internet para las sugerencias de texto.
  • ✓El código de participante y la clave que entrega el equipo de investigación.
  • ✓Unos 300 MB libres en el disco.

Cómo instalarla

  1. Descarga el instalador

    Usa el botón de arriba. Se guarda el archivo InteractorGate-Setup.exe en la carpeta de descargas.

  2. Ábrelo y permite que se ejecute

    Como es un prototipo, el instalador no está firmado y Windows puede mostrar «Windows protegió su PC». Elige Más información y luego Ejecutar de todas formas.

  3. Sigue el asistente

    Acepta las opciones por defecto. Al terminar quedará un acceso directo de InteractorGate en el escritorio.

  4. Calibra la mirada la primera vez

    Al abrir la aplicación aparecen puntos a pantalla completa. Síguelos con los ojos y, cuando se indique, mueve un poco la cabeza sin dejar de mirar el punto. Toma un par de minutos.

  5. Ingresa el código de participante

    Escribe el código (por ejemplo, P01) y la clave, y pulsa Enter. La sesión queda guardada para las siguientes veces.

Tus datos

La cámara no sale de tu equipo

Las imágenes se procesan en la propia computadora para estimar la mirada. No se guardan ni se envían a internet.

Solo un código, no tu nombre

Al servidor se envían el texto que escribes y las selecciones, asociados a tu código de participante.

Puedes retirarte cuando quieras

Sin dar explicaciones. En ese caso se eliminan tus datos. Todo se borra al terminar el estudio.
